Pitch numbers printed after OBSTACLE(...) in these captures come from a placeholder formula (1500 to 3500 Hz) that was removed on 2 Nov; the audible pitch is Brian's alert.c. The two 2026-10-18 logs are from the 1000 ms hold build. The hold is now 500 ms (FR10); the byte-loss and fault results still apply. The 500 ms fault timing is now measured (510 ms, 2026-11-01_fault_test_tx_unplug.txt). Not yet measured: NFR6 latency, long range.

The 2026-10-30 files are the current build (settle window sends CLEAR only, counters reset after configuration, BOOT debug line). The 2026-10-18 logs are an older build. Start-up differs by how the board starts: a cold plug-in loses 32 to 77 bytes before configuration (config OK at 2240 ms) and has a 0.9 s sensor silence after about 10 frames; a reset loses none (config OK at t=0 ms) but has the same silence after about 10 frames (3 of 3 captures on 1 Nov; the 30 Oct reset captures opened after it had ended). Cause not measured.
