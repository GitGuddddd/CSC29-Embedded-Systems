# Abbreviations used in the source (Barr-C 1.5.b)

| Short form | Meaning |
|------------|---------|
| ack | acknowledgement frame from the sensor |
| cfg | compile-time configuration (header only) |
| cms | centimetres per second |
| d_mm | distance in millimetres |
| hal | hardware abstraction layer |
| irq / isr | interrupt request / interrupt service routine |
| lcfg | link-time configuration (const data in a .c file) |
| ld2450 | HLK-LD2450 mmWave radar |
| ms | milliseconds |
| rte | runtime environment |
| rx / tx | receive / transmit |
| soup | software of unknown provenance |
| ttc | time to collision |
| FR / NFR | functional / non-functional requirement of the Group 29 report |
